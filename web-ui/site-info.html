About SSC Flix

SSC Flix is a practice-portal prototype designed to organise mock tests, previous-year questions, chapter practice and test review in one study workspace.

The current published version is a front-end demonstration. Some screens use sample content and preview interactions; it is not an official Staff Selection Commission website.

Contact

A dedicated support email or contact form has not been configured in this prototype. Please do not enter sensitive personal information into demonstration forms.

Contact channel: Not configured yet.

Frequently asked questions

Is SSC Flix an official SSC website?

No. It is an independent practice-portal prototype and is not presented as an official government or SSC service.

Are sign-in and account creation fully connected?

No. The current sign-in and account-creation screens demonstrate the interface only. Backend authentication is not connected.

Are test scores and rankings real?

No. The CBT and result screens are previews. Question evaluation, shared rankings and server-side attempt history are not connected yet.

Where is my practice preview saved?

Some preferences and test context are stored in this browser using local storage. Clearing browser site data may remove that local preview.

Test guidelines

  • Choose the relevant examination and test before starting practice.
  • Read the instructions and marking scheme shown on the test screen.
  • Use the question palette and review controls to navigate the demonstration CBT.
  • Do not treat the sample result as an official score or exam prediction.
  • Use a stable connection while loading pages that depend on third-party fonts or scripts.

System requirements

  • A recent version of Chrome, Edge, Firefox or Safari.
  • JavaScript enabled for interactive previews.
  • Local storage enabled for saving local preferences and preview context.
  • Internet access for third-party fonts and the Tailwind CSS CDN used by some screens.
  • A modern mobile, tablet or desktop screen. The interface is designed to be responsive.

Privacy policy · Prototype draft

This draft describes the current demonstration version and is not a final legal privacy notice.

Information stored in this browser

The prototype uses browser local storage for limited interface preferences and demonstration test context, such as selected examination, language and preview attempt information. This information remains in the browser unless site functionality or the user clears it.

Server-side collection

This static GitHub Pages prototype does not include a connected SSC Flix account database or a backend submission service. Do not use it to submit sensitive personal, financial or authentication information.

Third-party resources

Some pages load fonts and styling resources from Google Fonts and the Tailwind CSS CDN. Those providers may receive standard request data when your browser retrieves those resources. Their own privacy terms apply to those requests.

Data controls

You can clear this site's stored data through your browser's site-data settings. Doing so may remove saved local preferences and test-preview context.

Before collecting real user accounts, test answers or personal information, publish a reviewed privacy policy that reflects the production backend and actual data practices.
